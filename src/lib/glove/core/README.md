(`clients/crates/aico-web`), compiled to wasm by `just core` (cargo, then
`wasm-bindgen --target web`). Committed, so the site builds with bun alone;
never edited here. Rebuild after a change in `aico-protocol`, `aico-surface`,
`aico-surface-mai` or `aico-web`.
